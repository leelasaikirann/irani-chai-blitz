# Ustaad Ji's Irani Chai Blitz

A self-contained browser game. Open `index.html` in a browser to play.

## Publish it

This folder contains the complete static site. To get a public URL, deploy the folder to Netlify Drop or Firebase Hosting. Netlify Drop requires signing in and uploading this folder; Firebase Hosting requires a Firebase project and its CLI. No hosting account or deployment credentials were available in the current workspace, so no public URL has been created yet.
